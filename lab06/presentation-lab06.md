# Командная строка

**Командная строка** — способ взаимодействия пользователя с операционной системой посредством ввода команд в текстовом режиме.

Стандартные интерпретаторы в UNIX/Linux:

- `sh`
- `csh`
- `ksh`
- `bash`

### Формат команды

```
<имя_команды> <разделитель> <аргументы>
```

---

# Команда man

```bash
man <команда>
```

Клавиши управления:

- `Space` — на страницу вперёд
- `Enter` — на строку вперёд
- `b` — на страницу назад
- `q` — выход

---

# Команда cd

```bash
cd [путь_к_каталогу]
```

Файловая система UNIX — иерархическая система каталогов, подкаталогов и файлов.

Корневой каталог обозначается `/`.

Примеры:

- `cd /tmp` — переход в `/tmp`
- `cd ~` — переход в домашний каталог
- `cd -` — переход в предыдущий каталог

---

# Команда ls

```bash
ls [-опции] [путь]
```

Опция `-l` выводит подробную информацию:

- тип файла
- права доступа
- число ссылок
- владелец
- размер
- дата последней ревизии
- имя файла или каталога

---

# Команды mkdir и rmdir

### mkdir

```bash
mkdir имя_каталога1 [имя_каталога2...]
```

Опции:

- `-m` (`--mode`) — установка атрибутов доступа
- `-p` (`--parents`) — создание родительских каталогов

### rmdir

Удаляет только **пустой** каталог. Для удаления каталога с файлами — `rm -r`.

---

# Команды rm и history

### rm

```bash
rm [-опции] [файл]
```

- `-i` — запрос подтверждения
- `-r` — рекурсивное удаление

### history

```bash
history
```

Повторный вызов:

```bash
!<номер>
```

Модификация:

```bash
!<номер>:s/<старое>/<новое>/
```

# 2. Операции с /tmp

```bash
cd /tmp
pwd
ls
ls -a
ls -l
ls -la
ls -R | head -30
```

Разница:

- `ls` — только имена
- `ls -a` — с скрытыми файлами
- `ls -l` — подробно
- `ls -la` — подробно со скрытыми
- `ls -R` — рекурсивно

# 3. Создание каталогов

```bash
mkdir ~/newdir
mkdir ~/newdir/morefun
mkdir ~/letters ~/memos ~/misk
ls ~/ | grep -E "letters|memos|misk"
```

Результат:

```

memos
misk
```

---

# Удаление каталогов

```bash
rmdir ~/letters ~/memos ~/misk
ls ~/ | grep -E "letters|memos|misk"
```

Второй `grep` — пусто, значит удалено.

Попытка удаления `newdir`:

```bash
rm ~/newdir
```

Результат:

```
rm: cannot remove '/home/zhaoxinya/newdir': Is a directory
```

`rm` без `-r` не удаляет каталоги.

---

# Удаление подкаталога

```bash
rmdir ~/newdir/morefun
ls -R ~/newdir
```

Результат:

```
/home/zhaoxinya/newdir:
```

Каталог пуст, `newdir` остался.

# 6. Основные опции команд

| Команда | Опции |
|---------|-------|
| `cd` | `-` предыдущий каталог, `~` домашний |
| `pwd` | `-P` физический путь |
| `mkdir` | `-p` родительские, `-m` права |
| `rmdir` | `-p` удалить пустые родительские |
| `rm` | `-i` подтверждение, `-r` рекурсивно, `-f` принудительно |

Изучались через `man`:

```bash
man cd
man pwd
man mkdir
man rmdir
man rm
```
