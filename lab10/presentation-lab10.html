Три режима vi

Режим Назначение Как войти
Командный навигация, команды Esc
Вставки ввод текста i / a / o / …
Последней строки сохранение, выход, опции :

Управление курсором

Команда Функция
h j k l ← ↓ ↑ →
0 начало строки
$ конец строки
G конец файла
nG строка n
Ctrl+D пол-экрана вперёд
Ctrl+U пол-экрана назад
Ctrl+F / Ctrl+B страница вперёд / назад

Перемещение по словам

  • w / W — следующее слово
  • b / B — предыдущее слово
  • e / E — конец слова

Вставка текста

Команда Действие
i перед курсором
a после курсора
A в конец строки
I в начало строки
o новая строка после
O новая строка перед

Удаление и отмена

Команда Действие
x символ
dw слово
d$ до конца строки
d0 до начала строки
dd строку
ndd n строк
u отмена
U отмена изменений строки

Режим последней строки

Команда Действие
:w сохранить
:wq сохранить и выйти
:q выйти
:q! выйти без сохранения
:set nu номера строк
:set ic игнорировать регистр

Задание 1. Создание файла

mkdir -p ~/work/os/lab06
cd ~/work/os/lab06
vi hello.sh

Внутри vi:

  1. i — режим вставки
  2. Введён текст:
#!/bin/bash
HELL=Hello
function hello {
LOCAL HELLO=World
echo $HELLO
}
echo $HELLO
hello
  1. Esc — командный режим
  2. :wq — сохранить и выйти
  3. chmod +x hello.sh

Файл hello.sh создан, содержимое сохранено, права на выполнение установлены.

Задание 2. Редактирование файла

vi ~/work/os/lab06/hello.sh
  1. Курсор на конец HELL (2-я строка)
  2. i → заменить HELL на HELLO
  3. Esc
  4. Курсор на 4-ю строку → удалить LOCAL
  5. i → ввести local
  6. Esc
  7. Курсор на последнюю строку → o → ввести echo $HELLO
  8. Esc
  9. dd — удалить последнюю строку
  10. u — отменить
  11. :wq — сохранить и выйти
