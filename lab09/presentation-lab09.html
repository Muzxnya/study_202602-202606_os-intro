Что такое Midnight Commander

mc — псевдографическая командная оболочка для UNIX/Linux.

Запуск:

mc

Структура экрана

  • две панели со списками файлов
  • меню (доступно по F9)
  • командная строка внизу
  • экранные кнопки F1–F10

Функциональные клавиши

Клавиша Действие
F1 Помощь
F2 Меню пользователя
F3 Просмотр
F4 Правка
F5 Копирование
F6 Переименование/перемещение
F7 Создание каталога
F8 Удаление
F9 Меню
F10 Выход

Управление панелями

  • Tab — переключение между панелями
  • Ctrl+U — обмен панелями (в некоторых версиях — Unselect)
  • Ctrl+O — временное скрытие панелей
  • Ctrl+X D — сравнение каталогов

Режимы панели

  • Список файлов
  • Быстрый просмотр
  • Информация
  • Дерево

Пять меню mc

  • Левая панель
  • Файл
  • Команда
  • Настройки
  • Правая панель

1. Запуск mc

mc

Открылся двухпанельный интерфейс.

2. Структура экрана

  • Верхняя строка меню: Left, File, Command, Options, Right

  • Внизу — строка подсказки и функциональные кнопки:

    1Help 2Menu 3View 4Edit 5Copy 6RenMov 7Mkdir 8Delete 9PullDn 10Quit

3. Создание каталога

Нажата F7, введено имя STUD1, создан каталог:

/home/zhaoxinya/STUD1

4. Копирование каталога

  • В правой панели выбран .bashrc.d
  • F5 → окно копирования
  • Поле «to:» → ~/STUD1
  • Подтверждение < OK >

Каталог .bashrc.d скопирован в ~/STUD1. Размер STUD1 вырос с 0 до 18.

5. Просмотр содержимого STUD1

ls ~/STUD1/.bashrc.d

9. Встроенный редактор mc

Вызывается по F4.

Основные комбинации

  • Ctrl+Y — удалить строку
  • Ctrl+K — вырезать блок
  • Ctrl+U — вставить блок
  • Ctrl+O — сохранить
  • Ctrl+X — выйти
  • Ctrl+Z — отмена
