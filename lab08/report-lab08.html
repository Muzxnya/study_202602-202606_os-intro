Теоретические сведения

Три стандартных потока

  • stdin — стандартный ввод (дескриптор 0)
  • stdout — стандартный вывод (дескриптор 1)
  • stderr — вывод ошибок (дескриптор 2)

Перенаправление

1>filename        # stdout → файл (перезапись)
1>>filename       # stdout → файл (добавление)
2>filename        # stderr → файл
2>>filename       # stderr → файл (добавление)
&>filename        # stdout и stderr → файл

Конвейер

ls -la | sort > sorting_list

Команда find

find путь [-опции]

Примеры:

find ~ -name "f*" -print
find ~ -name "*.tmp" -exec rm {} \;

Команда grep

grep строка имя_файла

Проверка использования диска

df -h
du -a ~
du -sh ~

Управление задачами

gedit &                          # запуск в фоне
jobs                             # список задач
kill %номер_задачи               # завершение

Управление процессами

ps aux                           # список процессов
ps aux | grep gedit              # найти процесс
kill -9 PID                      # завершить
pkill -f gedit                   # завершить по имени

Ответы на контрольные вопросы

1. Какие потоки ввода-вывода вы знаете?

  • stdin (0)
  • stdout (1)
  • stderr (2)

2. Разница между > и >>

  • > — перезапись
  • >> — добавление

3. Что такое конвейер?

Передаёт вывод одной команды на вход другой:

ls -la | sort

4. Что такое процесс?

Процесс — выполняющийся экземпляр программы.

5. Что такое PID и GID?

  • PID — идентификатор процесса
  • GID — идентификатор группы

6. Что такое задачи?

Фоновые процессы текущей оболочки. Управление: jobs, kill %N.

7. top и http

  • top — интерактивный монитор процессов
  • httpd — HTTP-сервер

8. Команды поиска файлов

find — по имени и атрибутам; grep — по содержимому.

9. Поиск по контексту

grep "текст" файл

10. Объём свободной памяти

df -h

11. Объём домашнего каталога

du -sh ~

12. Удаление зависшего процесса

kill -9 PID
pkill -9 имя
