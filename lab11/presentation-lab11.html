Основные термины Emacs

  • Буфер — объект, содержащий текст
  • Фрейм — окно в обычном понимании
  • Окно — прямоугольная область фрейма
  • Область вывода — нижняя часть фрейма
  • Минибуфер — область ввода
  • Точка вставки — место вставки данных

Префиксы команд

  • C- = Ctrl
  • M- = Alt или Esc

Пример: C-x C-f = нажать Ctrl+x, отпустить, нажать Ctrl+f

Пример: C-x 3 = нажать Ctrl+x, отпустить, нажать 3

Ответы на контрольные вопросы (1/2)

1. Emacs — редактор на Elisp, поддерживает расширения, режимы, буферы, окна.

2. Сложности для новичков

Много комбинаций, специфическая терминология, режимы.

3. Буфер и окно

Буфер — текст, окно — область фрейма.

4. > 10 буферов?

Да, без ограничений.

5. Буферы при запуске

*scratch*, *Messages*, *GNU Emacs*.

Ответы на контрольные вопросы (2/2)

6. C-c | и C-c C-|

  • C-c |: Ctrl+C → Shift+\
  • C-c C-|: Ctrl+C → Ctrl+Shift+\

7. Разделение окна

C-x 2 — горизонтально, C-x 3 — вертикально.

8. Файл настроек

~/.emacs или ~/.emacs.d/init.el.

9. C-|

Зависит от режима. Переназначается через global-set-key.

10. vi vs emacs

vi — компактный, есть везде; emacs — мощный, расширяемый.
